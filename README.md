# ExpoIngenierías CSN

Sitio web estático para Expo-Ingenierías del Tecnológico de Monterrey, Campus Sonora Norte.

## El evento

Expo-Ingenierías es un evento académico de la Escuela de Ingeniería y Ciencias donde estudiantes de ingeniería presentan sus proyectos finales del semestre. Promueve la curiosidad científica, la experimentación, el pensamiento analítico y la comunicación técnica. Los proyectos participan en las categorías de Exploración, Enfoque y Especialización.

El evento será el **30 de noviembre de 2026, de 3:30 a 5:00 p. m.**, en el Salón de Congresos, Campus Hermosillo. Los profesores registran los proyectos del 20 al 27 de noviembre; el montaje de stands comienza a las 3:00 p. m.

**Nota:** Las fechas y categorías que aparecen actualmente en el sitio difieren de esta convocatoria y deben actualizarse antes de usarse como información oficial.

## Desarrollo local

Abre `index.html` en un navegador. El sitio utiliza HTML, CSS y JavaScript, sin compilación ni instalación de dependencias.

La [muestra virtual](muestra_virtual.htm) presenta los proyectos destacados y también puede abrirse directamente en el navegador.

## Despliegue en GitHub Pages

El sitio publicado está disponible en [GitHub Pages](https://dizzytlacuache.github.io/ExpoIngenierias-CSN/). El flujo [Deploy static content to Pages](https://github.com/DizzyTlacuache/ExpoIngenierias-CSN/blob/main/.github/workflows/static.yml) se ejecuta automáticamente al enviar cambios a `main`; también puede ejecutarse manualmente desde la pestaña **Actions**.

El flujo publica el contenido del repositorio mediante GitHub Actions y GitHub Pages, sin un paso de compilación. Para publicar cambios, intégralos en `main` y revisa el resultado del flujo en [Actions](https://github.com/DizzyTlacuache/ExpoIngenierias-CSN/actions). La fuente de publicación se configura en **Settings → Pages → Build and deployment → GitHub Actions**.
